# 라벨

PR마다 라벨을 **정확히 하나** 붙인다. GitHub가 새 저장소에 기본으로 만드는 라벨 중 아래 셋만 쓴다.

| 라벨            | 쓰는 때                                          |
| --------------- | ------------------------------------------------ |
| `bug`           | 버그 수정                                        |
| `documentation` | 문서만 바꾼 경우 (README, AGENTS.md, 스킬, 주석) |
| `enhancement`   | 새 기능, 기존 기능 개선, 리팩터링, 설정·CI 변경  |

## 고르는 순서

위에서부터 보고 처음 맞는 것 하나만 쓴다.

```text
버그 수정인가?           → bug
문서만 바꿨는가?         → documentation
그 밖의 모든 변경        → enhancement
```

## 붙이지 않는 라벨

`duplicate`, `good first issue`, `help wanted`, `invalid`, `question`, `wontfix`는 이슈용이거나 사람이 직접 붙이는 라벨이다. 자동으로 붙이지 않는다.

## 저장소에 라벨이 없을 때

라벨을 지웠거나 바꾼 저장소도 있다. 고른 라벨이 없으면 라벨을 만들거나 다른 라벨로 바꾸지 않고 **라벨 없이** PR을 만든다. `scripts/create-pr.sh`가 미리 확인해서 처리한다.
