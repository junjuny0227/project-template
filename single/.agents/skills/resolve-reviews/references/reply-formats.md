# 답글 형식

`resolve-reviews` 5단계에서 쓴다. 모든 답글은 한국어로 쓴다. 사용자가 승인한 답글만 단다.

## VALID — 반영함

```text
<abc1234>에서 반영했습니다. (근거: <출처>)
```

## VALID — 직접 수정 필요

```text
지적 사항이 타당합니다. 수정 범위가 커서 별도로 처리하겠습니다.
```

## INVALID

```text
이 프로젝트의 규칙과 달라 변경하지 않겠습니다.
근거: <출처> — "<규칙 인용>"
```

## PARTIAL — 반영함

```text
일부 타당하다고 판단해 <abc1234>에서 반영했습니다. (반영 범위: <범위>)
```

## PARTIAL — 반영 안 함

```text
검토 결과 이 방향으로는 적용하지 않기로 했습니다. (이유: <이유>)
```

## PENDING

```text
검토 중입니다. 추후 답변드리겠습니다.
```
